## 模组简介

### 什么是模组？

模组（Mod）是游戏的修改扩展包，可以添加新的：
- **原材料** - 如石油、木材、矿石等
- **产品** - 如汽车、电子产品、家具等
- **工人类型** - 不同技能和薪资的工人
- **合成配方** - 通过合成获得新材料或产品
- **初始设置** - 初始资金、初始材料等

### 模组文件格式

模组文件是 **JSON 格式**，文件扩展名为 `.json`，例如：`我的模组.json`

---

## 模组结构说明

一个完整的模组包含以下部分：

```json
{
    "name": "模组名称",
    "description": "模组描述",
    "author": "作者名",
    "version": "1.0",
    "initial_balance": 10000,
    "initial_materials": {
        "钢材": 100,
        "塑料": 50
    },
    "materials": [],
    "products": [],
    "initial_workers": [],
    "crafting_stations": []
}
```

### 字段详解

| 字段 | 类型 | 说明 | 必填 |
|------|------|------|------|
| `name` | 字符串 | 模组名称 | ✅ |
| `description` | 字符串 | 模组描述信息 | ✅ |
| `author` | 字符串 | 模组作者 | ✅ |
| `version` | 字符串 | 模组版本号 | ✅ |
| `initial_balance` | 数字 | 初始资金（元） | ❌ |
| `initial_materials` | 对象 | 初始材料库存 | ❌ |
| `materials` | 数组 | 原材料列表 | ❌ |
| `products` | 数组 | 产品列表 | ❌ |
| `initial_workers` | 数组 | 初始工人列表 | ❌ |
| `crafting_stations` | 数组 | 合成站配置 | ❌ |

## 使用模组制作器（推荐）

游戏内置了可视化模组制作器，无需编程即可创建模组。

### 打开模组制作器

1. 启动游戏
2. 点击菜单栏 **"模组"** → **"模组制作器"**

### 制作步骤

#### 1️⃣ 填写基本信息

在 **"基本信息"** 标签页中填写：
- 模组名称
- 描述
- 作者
- 版本
- 初始资金
- 合成站设置（可添加多个合成站）

#### 2️⃣ 添加原材料

在 **"原材料"** 标签页：
1. 点击 **"添加原材料"**
2. 填写：
   - 名称（如：钢材）
   - 成本（单价）
   - 单位（如：吨、个、升）
3. （可选）点击 **"设置合成配方"** 定义如何合成该材料

#### 3️⃣ 添加产品

在 **"产品"** 标签页：
1. 点击 **"添加产品"**
2. 填写：
   - 名称（如：汽车）
   - 售价
   - 生产时间（分钟）
3. （可选）点击 **"设置合成配方"** 定义生产所需材料

#### 4️⃣ 配置合成配方

在 **"合成配方"** 标签页可以查看所有可合成的材料和产品配方。

#### 5️⃣ 添加工人

在 **"工人"** 标签页：
1. 点击 **"添加工人"**
2. 填写：
   - 姓名
   - 技能等级（1-5，越高效率越高）
   - 日薪

#### 6️⃣ 保存模组

点击底部 **"保存模组"** 按钮，选择保存位置。

#### 7️⃣ 导入模组

在游戏中：**"模组"** → **"导入模组"**，选择保存的 JSON 文件。

### 原材料（materials）字段说明

```json
{
    "name": "材料名称",
    "cost": 单价（数字）,
    "unit": "单位",
    "is_craftable": 是否可合成（true/false）,
    "materials_required": {
        "所需材料名称": 数量
    },
    "products_required": {
        "所需产品名称": 数量
    }
}
```

### 产品（products）字段说明

```json
{
    "name": "产品名称",
    "sale_price": 售价（数字）,
    "production_time": 生产时间（分钟，数字）,
    "is_craftable": 是否可合成（true/false）,
    "materials_required": {
        "所需材料名称": 数量
    },
    "products_required": {
        "所需产品名称": 数量
    }
}
```

### 工人（initial_workers）字段说明

```json
{
    "name": "工人姓名",
    "skill_level": 技能等级（1-5 的整数）,
    "salary": 日薪（数字）
}
```

### 合成站（crafting_stations）字段说明

```json
{
    "name": "合成站名称",
    "capacity": 产能（整数，表示最大同时工作数）
}
```

## 常见问题

### Q1: 模组保存后在哪里？

模组文件保存在您选择的任何位置。建议创建一个专门的文件夹存放模组，例如：
```
Factory-Simulator/
└── Mods/
    ├── 工业革命.json
    ├── 基础建材.json
    └── 电子科技.json
```

### Q2: 如何分享我的模组？

直接将 `.json` 文件发送给其他玩家，他们通过游戏菜单 **"模组" → "导入模组"** 即可使用。

### Q3: 模组加载后没有效果？

请检查：
1. JSON 格式是否正确（可用在线 JSON 验证工具检查）
2. 必填字段是否完整（name, description, author, version）
3. 数值是否为有效数字
4. 合成配方中引用的材料/产品是否在模组中存在

### Q4: 可以修改现有游戏内容吗？

模组是**添加**新内容，不会修改游戏原有内容。每次只能激活一个模组。

### Q5: 技能等级有什么用？

工人技能等级（1-5）影响工作效率：
- 技能等级越高，生产/合成速度越快
- 公式：效率 = 1 + (技能等级 - 1) × 0.2
- 5 级技能工人比 1 级快 80%

### Q6: 合成和生产有什么区别？

- **生产**：在生产线进行，需要时间因产品而异
- **合成**：在合成站进行，固定需要 60 分钟，可将多种材料组合成新物品

### Q7: 如何创建复杂的产业链？

使用 `materials_required` 和 `products_required` 创建依赖关系：

```json
// 汽车需要引擎和轮胎
{
    "name": "汽车",
    "sale_price": 50000,
    "production_time": 240,
    "materials_required": {
        "钢铁": 10,
        "橡胶": 4
    },
    "products_required": {
        "引擎": 1,
        "轮胎": 4,
        "方向盘": 1
    }
}
```

## 💡 创作技巧

1. **从小开始**：先创建简单的模组，熟悉格式后再做复杂的
2. **平衡数值**：确保材料成本、产品售价合理，避免破坏游戏平衡
3. **命名清晰**：使用有意义的名称，方便识别
4. **测试验证**：创建后在游戏中测试，确保能正常生产和合成
5. **记录配方**：复杂模组建议单独记录配方树
